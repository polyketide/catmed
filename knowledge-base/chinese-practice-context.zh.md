# 中文语境下的实际诊疗图景 —— 主人会描述什么，以及它和证据在哪里分岔

> 生成于 2026-07-27 · 语料实测 + 逐条比对已核实文献 · **本文件不是证据，也不是流行病学**
>
> **⛔ 这是"语境"，不是"依据"。** 它记录的是：中文使用者向 agent 描述病情时，**大概率会出现什么样的方案、用药和说法**。目的只有一个——让 agent **听得懂、且知道该在哪里提醒**。
> 本文件中的任何一条**都不能作为医学结论被引用**。所有医学判断仍然只来自它指向的、经逐字核对的知识库文件。
>
> **数据来源与去敏感处理。** 频次来自一份中文猫肿瘤主人社群的公开可见资料（约五百份成员备注 + 一周消息）的**统计**。本文件**不含**：社群名称、成员昵称、猫名、逐个案例、城市分布，或任何可定位到个人的信息。**原始语料未进入本仓库，也不会进入。**
> ⚠️ **这是一个高度自选的人群**（愿意化疗、会上网、能找到组织），**它准确描述的是我们的使用者，不是猫肿瘤在猫群体中的真实分布。** 不得用于推断发病率、生存率或任何预后。

## 2. 会遇到什么样的支持治疗——以及三处该提醒的地方

### 2.1 升白针（人用 G-CSF）使用非常普遍

**这是被讨论最多的支持治疗手段。** 用的多为**人用**重组 G-CSF。

> ⚠️ **该提醒的点：反复注射人用 G-CSF 可使猫产生与自身 G-CSF 交叉反应的中和抗体**，反而导致中性粒细胞减少。社群中已自发观察到"有的猫后来打了升不上去"——**那是有文献的机制，不是运气**。→ [`gcsf-and-chemotherapy-neutropenia.md`](gcsf-and-chemotherapy-neutropenia.md)
>
> ⚠️ 另见：偶有在**中性粒细胞正常**时使用的情形，社群内部已有人正确质疑。**决定依据是当次 CBC，不是排期。**

### 2.2 贫血：EPO/DPO、输血与"补血"制剂

主人普遍知道看**网织红细胞**（这一点相当专业），但处理方式分歧很大：有的一见 HCT 下降即用 DPO，有的用口服"补血"类制剂，有的观察。

> **⭐ 该提醒的点，而且它同时切向两边——这是本文件最重要的一条。**
>
> 知识库 §10.1 的纪律是**先分类，再处理**：按网织红细胞分再生/非再生；并设**严重度门槛**——*"轻度贫血（如 HCT 在 20% 后段）通常根本不需要针对贫血的治疗；ESA 与输血是给有症状或严重病例的。"*
>
> - **对"一见掉就打 DPO"**：达贝泊汀的猫证据来自**肾性**贫血（14/25 应答），**不能直接外推到肿瘤相关贫血**，且不良反应包括呕吐、高血压、癫痫、发热。**未分类即用药，正是 §10.1 警告的做法。**
> - **对"那就吃补血制剂"**：⚠️ **这不是一个更安全的默认。** 非处方"补血"制剂**没有支持证据**；更要紧的是，若其中含**铁**，而贫血属**炎症性贫血（ACD）——肿瘤患者最常见的那一种**——则**口服铁基本无效**（吸收环节正是被阻断的那一步），**且有已记载的危害**：氧化应激、加重炎症、菌群紊乱等。
>
> **所以"打针"与"吃补品"这个二选一本身可能是错的问题。** 真正的问题是：**这只猫的贫血属于哪一类，严重到需要处理吗？** → [`supportive-and-palliative-care.md`](supportive-and-palliative-care.md) §10.1

### 2.3 输血：常在**未验血型**的情况下进行

> ⚠️ **该提醒的点：猫可能死于第一次输血。** 只有 AB 同型才安全，而且 AB 同型是**必要非充分**（Mik 抗原；14.9% 从未输过血的猫存在非-AB 交叉配血不合）。**首次输血前也须验血型 + 交叉配血。** → [`blood-types-and-transfusion-compatibility.md`](blood-types-and-transfusion-compatibility.md)

### 2.4 喂食：强饲远比放管常见

主人普遍**害怕放管**、努力强饲，直到"猫看见针管就跑"。

> ⚠️ **该提醒的点**：2022 ISFM 共识明确写道，**因"临床医师或照护者的顾虑"而拖延放置饲管，可能拖慢恢复、加重营养不良**。但并发症也是真实的（一项研究 44.4%）。**两侧都要说。** → [`assisted-feeding-and-feeding-tubes.md`](assisted-feeding-and-feeding-tubes.md)

## 3. 主人真正在问什么（用于确定回答的优先级）

按提问频次由高到低：**化疗方案与轮次 → 医院与医生选择 → 副作用处理 → 费用与药品获取 → 具体用法剂量 → 检查与诊断 → 血常规/骨髓抑制 → 食欲呕吐腹泻 → 预后与生存期**。

> **⭐ 最要紧的一条错配：预后与生存期是提问最少的一类（约 2%），而知识库覆盖最充分的恰恰是预后。**
>
> 一位主人给出的解释很可能是对的：**对一只已经在治疗中的猫，群体统计回答不了"我家这只会怎样"；文献回答的是他们没在问的问题。** 他们绝大多数时间需要的是**执行层面的支持**——这次能不能打、指标低了怎么办、这个反应正不正常。
>
> **对 agent 的含义**：不要用预后数据回答一个执行问题。先回答眼前这一步，预后只在被问到时给。
>
> ⛔ **两类问题必须拒答**：**医院/医生推荐**与**药品购买渠道**（合计约占提问的 17%）。这超出证据能回答的范围，且涉及商业与合规。

## 4. 使用纪律

1. **本文件只提供语境与提醒的触发点，不提供任何医学结论。** 每一条"该提醒的点"都必须落到它指向的文件，并以那里的逐字证据作答。
2. **不得把这里的任何比例当作发病率、有效率或生存率。** 它描述的是一个自选人群的行为，不是疾病。
3. **不得据此评判任何具体医生或医院。** 观察到的模式有多种解释（可及性、成本、当地惯例、患者构成），**本文件不裁决其中任何一种**。
4. **模式会漂移。** 用药习惯、可及性和社群构成都随时间变化；遇到与此处不符的描述，**以主人的实际描述为准**，并如实说明这里记录的只是常见情形。
